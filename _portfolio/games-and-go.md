Games and Go is an IEEE SSIT VIT open-source project that brings classic games such as Tic-Tac-Toe and Pacman to the web. I led the community project as an administrator, helping contributors collaborate through GSSoC and Hacktoberfest. The project is built with React, HTML, CSS, and Bootstrap.
